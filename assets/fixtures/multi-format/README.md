# Multi-format feasibility corpus

This directory contains deterministic fixtures generated by
`scripts/feasibility/generate-multi-format-corpus.py`.

- `representative.docx`: page geometry, headers/footers, styled text, table, image,
  page break, Japanese text.
- `representative.xlsx`: sheets, styles, merged cells, formulas, conditional
  formatting, chart, Japanese text.
- `representative.pptx`: positioned shapes, image, styled text, chart, multiple
  slides, Japanese text.
- `stress-100k-cells.xlsx`: bounded large-sheet performance and limit fixture.
- `reference-shapes.png`: deterministic embedded image.
- `external-image.docx`: external image relationship targeting a local test
  endpoint; conversion must not request it.
- `macro-marker.docx`: inert `vbaProject.bin` marker; preflight must reject it.
- `oversized-document.docx`: highly compressed document XML expanding beyond
  32 MiB; preflight must reject it before parsing.
- `manifest.json`: SHA-256, compressed size, entry count, and total uncompressed
  size for every generated fixture.

Trusted reference artifacts are generated separately by the evaluated Office
engine and are not accepted as production output.
